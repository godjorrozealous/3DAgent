# 指挥大厅逼真化 + 策略驱动动画 + 复盘私聊增强 + 干预线索管理 设计

日期：2026-07-28
状态：已获用户三轮澄清确认（3D 参考图两张已提供）

## 背景

基于已交付的「指挥室增强」分支（双摘要卡/模板策略管理/交互式复盘），用户实测后提出 7 项新修改。本设计覆盖全部 7 项。

## 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 3D 参考 | 用户提供的两张 3d66 智慧大厅截图（明亮写实风） |
| 3D 风格 | 3D 场景整体切换明亮写实；2D 面板/HUD 保持暗色玻璃拟态 |
| 实时干预口径 | 严格：实时诊断全程禁止人工干预，干预仅在复盘中 |
| 外部数据/改查询 | 编排层覆盖方案（不动 PLD/Mock） |
| 鸟害未调用 | 系测试残留排除所致；重置 PLD 会话做干净验证 |
| 确认/私聊弹窗 | 合并为一个 ~720px 大弹窗 |
| 手填数据形式 | 自由文本 + 可选时间段输入 |
| 策略激活 | 干预线索随策略保存，激活时编排层自动重放 |
| 不调用智能体呈现 | 亮一下就灭（~0.6s） |
| 异议入口 | 四个快捷按钮 + 自由聊天双入口 |

## 1. 3D 指挥大厅明亮写实改造（CommandRoom.js）

参考图元素 → 实现映射：

| 参考图元素 | Three.js 实现 |
|---|---|
| 白色环形大厅外壳 | 浅色（#e8ecef）圆柱壳体墙面，MeshStandardMaterial 高 roughness |
| 落地弧形玻璃幕墙 + 外景 | 半透明玻璃材质墙面（transmission/opacity），墙外简单天际线平面（渐变天空 + 远山剪影纹理） |
| 格栅透光天窗吊顶 | 顶部格栅几何（重复梁条）+ 大面积自发光顶板模拟日光，主光源改为明亮环境光 + 顶部平行光 |
| 正面弧形巨幅视频墙 | 弧形平面（CylinderGeometry 片段）挂深色屏，canvas 纹理绘制数据可视化（波形/仪表盘/柱状图，青蓝色调），内容随诊断状态更新 |
| 白色弧形桌排 + 座椅 + 显示器 | 每席位：白色弧形桌台（圆环片段挤出）、简约座椅、桌面小显示器（canvas 纹理显示该智能体状态） |
| 整体光照 | 亮色调：环境光强度提升、色调映射调整为明亮写实；保留席位状态灯（青/琥珀/红）作为功能色 |

- 布局骨架不变：6 席位（司令员居中前、4 诊断工具两侧、审核员）+ 策略浮牌 + 黄色光束（仅动画逻辑改造，见 §2）。
- 2D 信息面板/HUD/弹窗保持现有暗色玻璃拟态，不改配色。

## 2. 策略驱动诊断动画（agent_manager.py）

- 后端在 PLD `thinking` 事件中解析「诊断计划」文本，正则提取 `(\w+DiagnosisTool)` 得到本轮**实际计划调用**的工具列表 `planned_tools`。
- 仅 `planned_tools` 中的工具席位进入 RUNNING、出现黄色光束与「通过 MCP 服务调用…」日志。
- 计划外工具（季节跳过/策略排除/LLM 未选）执行「亮一下就灭」：席位 RUNNING ~0.6s → idle，事件流一句「按 LLM 诊断策略，本轮未调用该工具（条件不满足）」（复用现有文案，移到此处）。
- 解析失败兜底：退回现状（四席位全亮），保证不阻断流程。
- 复盘模式同逻辑；被人工排除的工具即使在计划内也不亮（排除列表优先于计划）。

## 3. 鸟害未调用：会话重置验证

- 根因：持久化会话残留测试期的 `excluded_tools: ["BirdDamageDiagnosisTool"]`。
- 实施：编排层新增会话重置能力（调用 PLD 新会话/清状态接口；若 PLD 无重置接口则删除 sessions.json 中该会话后重启验证——验证脚本内操作，不改 PLD）。
- 干净会话跑一次诊断，断言：鸟害工具被调用并返回结果；夏天覆冰被跳过。
- 若干净会话下鸟害仍被 LLM 漏调，记录证据并向用户报告（PLD 提示词侧问题，另行评估，不在本期改动 vendor）。

## 4. 策略 HUD 清晰化（App.vue + CommandRoom.js 浮牌）

HUD 卡片改为两行：
- **调用**：雷电×1.0 风偏×0.8 鸟害×0.6 ……（会话快照 active_weights 全量列出，中文名映射）
- **排除**：鸟害（人工）/ 覆冰（季节条件）（区分来源：excluded_tools=人工，计划外=条件）
3D 策略浮牌同步此格式。无排除时第二行显示「排除：无」。

## 5. 实时禁干预 + 保存策略命名

- **实时禁干预**：
  - 前端：诊断运行中（store.running 且非复盘）ChatModal 输入框禁用，提示「诊断执行中，复盘时可干预」。
  - 后端：`handle_message` 的 chat 分支在实时运行期间拒绝干预类指令，回复聊天消息「实时诊断执行中不接受干预，请在复盘重跑中进行」（闲聊性问候仍可走 PLD general 意图——但简化起见运行中一律拒绝并提示）。
- **保存需命名**：所有保存入口（TopBar 保存按钮 + 保存提醒弹窗的「保存策略」）改为先弹命名弹窗：预填建议名 `策略_YYYYMMDD_HHmm`，可编辑；确认后以该名保存（PLD 技能名转安全 slug：中文保留、空格转下划线）；重名自动追加 `_2`/`_3`。
- 复盘中的干预/确认/审核流程不变（确认弹窗被 §6 大弹窗取代）。

## 6. 复盘合并大弹窗（新组件 AgentSessionModal.vue，~720px）

复盘中点击工具确认（或点击诊断智能体席位私聊）打开统一大弹窗：

- **顶部**：智能体/工具名 + 倾向 + 置信度。
- **结果区**（上半部，可滚动）：structured_data 全字段表 + 原始子报告 raw_text。
- **对话区**（中部）：与该智能体的私聊记录；输入框自由聊天。编排层给每条消息自动附加当前会话上下文前缀（「[当前会话：雅湖线 2025-05-08 19:46 跳闸诊断]」），限定讨论范围在当前线路会话内。
- **操作区**（底部）：四个快捷异议按钮（重新检查 / 数据不对去掉 / 调整权重[数值输入] / 手填数据）+ 可选时间段输入（起止时间文本）+「无异议」按钮（仅复盘确认模式显示）。
- 快捷按钮行为：点击后在对话区生成一条对应指令消息并发送（与自由聊天同管线），后端映射为 recheck/exclude/adjust_weight 指令或覆盖层记录。
- **手填数据/时间段**：记入 `value_overrides` 覆盖层（前端席位与摘要展示改后值），同时自动生成 modify_report 指令注入报告（「将{tool}相关数据修正为…」）。
- 确认队列逻辑不变：大弹窗在确认模式下处理队列头，「无异议」/异议提交后出队下一个。

## 7. 干预标签口径 + 干预线索保存/重放

- **摘要卡标签**：只显示**本轮新增**干预——后端 `_finish_run` 已维护 action_log 基线，report_summary 事件的 action_log 字段改为本轮增量（不再下发全量历史）。
- **干预线索（intervention_trail）**：后端新增本轮干预线索列表，逐条记录：{kind: exclude/weight/override/external_data/time_range/report_modify, tool?, value, text, time}。每轮开跑清空。
- **保存策略**：命名保存时，PLD 存权重+排除（现有），干预线索以策略名存入编排层本地 `data/strategy_trails.json`。
- **激活自动重放**：激活自定义策略时，PLD 技能生效后，编排层读取该策略线索逐条重放：覆盖层类（override/external_data/time_range）直接恢复展示；报告类（report_modify）逐条下发 modify_report（复用 `_wait_pld_idle`）；排除/权重已由 PLD 技能承载，跳过。重放结果记入事件流。

## 10. 错误处理

- 计划解析失败 → 四席全亮兜底（现状行为）。
- 策略重放中 PLD 失败 → 事件流记错误并继续下一条。
- 命名冲突 → 自动追加序号并在事件流说明。
- 会话重置失败 → 报错提示，不阻断诊断。
